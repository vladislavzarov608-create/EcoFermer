ОБНОВЛЕНИЕ ФОТОГРАФИЙ ЭКОФЕРМЕР

1. Распакуйте архив в отдельную папку на компьютере Windows.
2. Нажмите правой кнопкой мыши на файл ПОДГОТОВИТЬ-ФОТОГРАФИИ.ps1.
3. Выберите «Выполнить с помощью PowerShell».
   Если Windows блокирует запуск, откройте PowerShell в этой папке и выполните:
   powershell -ExecutionPolicy Bypass -File .\ПОДГОТОВИТЬ-ФОТОГРАФИИ.ps1
4. Скрипт скачает именно те фотографии, которые уже указаны в исходном дизайне, в assets/images и заменит ссылки на локальные.
5. В GitHub откройте репозиторий EcoFermer → Add file → Upload files.
6. Загрузите ВСЁ содержимое папки ekofermer-store, включая assets/images, поверх текущих файлов.
7. Нажмите Commit changes.
8. Через несколько минут откройте сайт и нажмите Ctrl+F5.

Важно: скрипт не меняет логику каталога, корзины и админ-панели. Он только переносит фотографии в assets/images и переключает ссылки на локальные файлы.
